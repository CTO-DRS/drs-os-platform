# دليل التثبيت — حزمة DRS OS 0.3.1-phase3 (ألفا)

الحالة: **BUILD VERIFIED — RUNTIME NOT VERIFIED**. الملفات الثلاثة بُنيت
وجُرِّبت وتحققت بنيويًا (اسم الحزمة، الإصدار، الصلاحيات الصفرية، التوقيع)،
لكن التشغيل الفعلي على جهازك هو ما يثبت السلوك — هذه نسخة تقييمية مبكرة
وتُثبَّت على مسؤوليتك.

## تحذيران إلزاميان

1. **توقيع تصحيح (debug)**: كل APK موقّع بمفتاح تصحيح لأغراض التقييم فقط.
   لا تُوزّعها كنسخة نهائية ولا تعتمد عليها كأداة إنتاج.
2. **صلاحيات صفرية**: لا يطلب أي من التطبيقات الثلاثة أي صلاحية أندرويد.
   إن ظهر لك طلب صلاحيات أثناء التثبيت أو التشغيل فهذا يعني أن الملف ليس
   من هذه الحزمة — أوقف التثبيت فورًا.

## التحقق قبل التثبيت (من جذر الحزمة)

```bash
sha256sum -c SHA256SUMS.txt
```
يجب أن تنجح كل الأسطر (`OK`). أي سطر `FAILED` يعني ملفًا تالفًا — لا تثبّته.

## التثبيت عبر adb

```bash
adb install -r apks/DRSSettings-0.3.1-phase3-debug.apk
adb install -r apks/DRSAutomation-0.3.1-phase3-debug.apk
adb install -r apks/DRSSecurityCenter-0.3.1-phase3-debug.apk
```

فعّل «تصحيح USB» على الجهاز أولًا. على أنظمة أندرويد الحديثة قد يظهر
تأكيد تثبيت عبر USB — وافق عليه.

## التطبيقات

| التطبيق | اسم الحزمة | الغرض في ألفا |
|---|---|---|
| إعدادات DRS | `os.drs.settings` | معلومات عن النسخة والجهاز والسياسات (قراءة فقط) |
| أتمتة DRS | `os.drs.automation` | قواعد حتمية محلية + سجل تدقيق؛ تنفيذ الإجراءات مُسجَّل كطلبات دون تنفيذ فعلي في هذه النسخة |
| مركز أمان DRS | `os.drs.security` | حالة المنصة المقروءة بلا صلاحيات، بلا أحكام مُخترعة |

## حل المشكلات

- **«تطبيق غير مثبت» / تعارض**: إن كانت لديك نسخة أقدم (0.3.0) بنفس اسم
  الحزمة وموقّعة بمفتاح تصحيح مختلف، أزِل النسخة القديمة أولًا:
  `adb uninstall os.drs.automation` (وكذلك للتطبيقين الآخرين).
- **فشل التحقق `sha256sum -c`**: تأكد أنك تنفّذ الأمر من **جذر الحزمة**
  (المجلد الذي يحتوي `SHA256SUMS.txt` مباشرة) — التنفيذ من مجلد أب يفشل
  رغم سلامة الملفات.
- **التطبيق لا يفتح**: هذه النسخة تستهدف Android 10 (API 29) فما فوق.
  أرسل لقطة شاشة لأي شاشة مكسورة لمعالجتها في الإصدار التالي.
